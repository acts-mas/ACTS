01 THE IDEA

More agents.
More messages.
Better answers?

Not every exchange helps. Effective collaboration depends on connecting complementary roles at the right moment.

LLM multi-agent systems can bring together different perspectives, but repeated communication adds token overhead. Fixed graphs cannot adapt as reasoning evolves, while topology schedulers may overlook agent roles and the structure of the communication graph.

ACTS learns the communication policy itself. Role-conditioned relational attention selects directed partners. A topological attention mixer uses the current graph to evaluate team decisions during centralized training. The scheduler balances task performance and token use while the backbone LLMs remain frozen.

Read the research summary +

We propose a role-aware framework for adaptive communication-topology scheduling in LLM-based multi-agent collaboration. ACTS separates communication-mode selection from partner selection: local action-value functions select a mode, while relational attention assigns directional relevance scores using role information and recurrent agent states. Together, modes and partner sets define a variable-cardinality directed graph for the next round.

Under centralized training with decentralized execution, a topological attention mixer encodes incoming and outgoing neighborhoods of the pre-decision graph to learn topology-dependent utility weights. Evaluations across nine benchmarks report macro-average accuracies of 75.01% on GPT-OSS-120B and 69.43% on DeepSeek-V4-Flash, improving over Agent Q-Mix by 3.18 and 6.19 percentage points, respectively.

02 THE METHOD

Two kinds of attention.
One coordinated team.

Select useful interactions at execution time.
Learn their value through topology-aware training.

ARELATIONAL ATTENTIONPartner selection

Connect complementary roles.

Agent roles and recurrent local states determine directional relevance scores. Communication modes and above-mean attention scores select a variable number of partners for the next round.

roles + local context → directed partner scores → Gt+1
BTOPOLOGICAL ATTENTIONValue factorization

Learn contributions in context.

The centralized mixer encodes incoming and outgoing neighborhoods in the current graph Gt. Nonnegative attention weights combine local utilities into the team action value.

current graph + global state → utility weights → Qtot

Timing matters. The mixer evaluates the current context Gt; communication actions construct Gt+1 for the next round. The centralized mixer is used during training.
