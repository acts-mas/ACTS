01 ABSTRACT

Communication is a design problem.

More agents do not automatically make a team better. The useful question is which agents should exchange information, in which direction, and when an additional exchange is worth its token cost.

ACTS learns a role-aware communication policy for LLM multi-agent collaboration. Local action values select a communication mode, while relational attention scores directed partners. These choices form a variable-cardinality graph for the next round.

During centralized training, a topological attention mixer encodes the current graph and assigns topology-dependent utility weights. Across nine benchmarks, ACTS reaches 75.01% macro accuracy with GPT-OSS-120B and 69.43% with DeepSeek-V4-Flash, improving over Agent Q-Mix by 3.18 and 6.19 percentage points.
